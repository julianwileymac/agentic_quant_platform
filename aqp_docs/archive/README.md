# Archive policy

This folder tracks documents that are no longer canonical runbooks but are
kept for historical context, auditability, or rollback analysis.

## Categories

- `plans/` — one-off planning prompts and execution plans.
- `reports/` — point-in-time audit or verification reports.
- `incidents/` — time-bound incident notes and hotfix logs.

## Active vs archive rule

- **Active** docs live under `aqp_docs/`, `aqp_platform/deployments/`, and root onboarding
  files (`README.md`, `CONTRIBUTING.md`, `AGENTS.md`, `WORKFLOW.md`).
- **Archive** docs are historical and should never be treated as current setup
  or deployment instructions.
