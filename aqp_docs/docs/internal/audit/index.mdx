## Action items

The docs team reviews this page at the start of every month and:

1. Reassigns ownership where the CODEOWNERS routing was wrong.
2. Closes issues that are no longer relevant.
3. Opens follow-up PRs for the top 5 highest-traffic +
   lowest-helpfulness pages.
4. Rolls up findings into the next release-notes entry under
   `audience: technical`.
